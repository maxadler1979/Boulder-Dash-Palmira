## О проекте

Boulder Dash для **Радио-86РК** (Пальмира) — ручной порт на C оригинальной C64-версии 1984 года под советский 8-битный компьютер на КР580ВМ80А (Intel 8080). Запускается в эмуляторе **Emu80**.

- **Язык:** C (pre-ANSI) с обильными вставками `#asm … #endasm` на ассемблере 8080
- **Компилятор:** z88dk `zcc +radio86` → чистый бинарник 8080 `a.bin`
- **Референс:** дизассемблер C64 (6502) лежит в `c64/boulder_dash/`

## Сборка и запуск

```bash
zcc +radio86 main.c bd_levels.c caves_zx.c game_logic.c rockford.c text_util.c sprite_routines.c tiles.c labirint.c title.c -create-app
python make_rkl.py
```

`compile.bat` делает и то и другое. Результат: `blddash.rkl` → загрузить в Emu80 (платформа Радио-86РК).

## Карта памяти и жёсткий лимит

```
0x0000 – 0xA5FF   Бинарник игры (загружается с 0x0000, НЕ должен заходить за 0xA5FF)
0xA600 – 0xB5FF   Видеопамять (78 байт/строка, экран с 0xA600+156=0xA69C)
0xB600+            Стек
0xD000 – 0xD0??   Таблица смещений строк (sm_y[52], строится create_table())
0xD800 – 0xDFFF   Память знакогенератора (RU10)
0xCC00 – 0xCCFF   PIT8253 таймер (звук)
0xC000 – 0xC001   Кадровый импульс ВГ75 (vsync)
0xC200             Контроллер клавиатуры
```

**КРИТИЧНО:** бинарник растёт вверх от 0x0000. Если превысит `0xA5FF` (42495 байт), он затрёт видеопамять. Всегда проверяй `wc -c a.bin` после добавления кода. Цель: **≤ 42300 байт** для безопасного запаса до 0xA600.

## Архитектура

### Главный цикл (`main.c`)
Вход → `show_palmira_intro()` → `show_claude_logo()` (если не пропущено) → `show_title()` → `while(1) { init_game_for_cave(); … game_tick_step(); camera_follow_rockford(); show_window(); update_hud(); sprites_anim(); sound_update(); tick_wait(); }`

Фиксированный темп: **VSYNC_HZ 59** / **TICKS_PER_SEC 8** — `tick_begin()`/`tick_wait()` выдерживают ровно 8 тиков/с по кадровому импульсу ВГ75. Таймер пещеры считает реальные секунды.

### Коды объектов (значения work_cave)
`0x00` пусто, `0x01` сталь, `0x02` земля, `0x03` кирпич, `0x04` валун, `0x06` алмаз, `0x08` выход, `0x0A` амёба, `0x0B` magic wall, `0x0C–0F` падающие/scanned, `0x10–17` светлячок/бабочка (4 направления), `0x18–21` стадии взрыва, `0x22` Rockford, `0x23`+ активные/scanned.

### Оптимизации (июль 2026)
- **Скан физики:** цикл 800 клеток на asm, 33 такта/клетку. Предфильтр `pp_bfast()` пропускает неподвижные валуны/алмазы одним чтением памяти. Колонка вычисляется по требованию из номера слота.
- **Рендерер:** `shadow[]` байтовый (хранит код объекта, 0xFF = всегда грязная). BC/DE/HL живут в регистрах все 12 колонок — ни одного `LHLD`/`SHLD` во внутреннем цикле. Вызов на ячейку, шаг строки через стек.
- **`falling_tick`:** HL=клетка, DE=клетка+40 живут в регистрах, `is_round()` заинлайнен.
- **Амёба:** чистый asm, младший байт `GetRand()` вместо `random(0,256)` через библиотечное деление.
- Время кадра: ~80мс → ~35мс.

### ⚠️ Грабли zcc
**Никаких апострофов и кавычек в `#asm`-комментариях** — препроцессор zcc считает `'` началом символьной константы и глотает всё до следующего апострофа, включая `#else`/`#endif`. Симптом: `error: No matching #if`. Писать `couldnt`, не `couldn't`.

## Защита бренда (`title.c`)

Строки "PALMIRA ORIGINAL SOFTWARE" и спрайты букв защищены от бинарного патчинга:

- **XOR-строки:** `brand_palmira_enc[]` / `brand_software_enc[]` — декодируются на лету функцией `brand_decode()` с ключами, производными от чексуммы спрайтов. В бинарнике название бренда выглядит как случайные байты.
- **Чексумма спрайтов:** `brand_verify()` считает 16-битную сумму всех 11 больших буквенных спрайтов (B_let..h_let, 694 байта подряд). Ожидаемое значение: `0x8715`. Вызывается из `show_palmira_intro()`.
- **Ключи:** `BRAND_KEY_PALMIRA = 0x15` (младший байт чексуммы), `BRAND_KEY_SOFTWARE = 0x87` (старший байт).
- **Изменение любого спрайта буквы меняет чексумму** → ключи перестают совпадать → строки декодируются в мусор. Изменение закодированных строк требует знания ключей, которые зависят от чексуммы.

Для обновления спрайтов: пересчитай чексумму, обнови `BRAND_SPRITE_CSUM`, `BRAND_KEY_PALMIRA`, `BRAND_KEY_SOFTWARE` и перекодируй строки бренда.
