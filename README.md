# Boulder Dash для Радио-86РК (Пальмира)

Ручной порт C64-оригинала 1984 года на советский 8-битник
(КР580ВМ80А = Intel 8080). Собирается z88dk `zcc +radio86`,
запускается в эмуляторе **Emu80**.

Это рабочая игра на грани возможностей машины: 20 пещер C64,
физика один-в-один с оригиналом, dirty-cell рендер 12×12,
фиксированные 8 тиков/с по кадровому импульсу ВГ75.

## Готовые образы

В [`bin/`](bin/) лежат актуальные бинарники для Emu80:

| Файл | Платформа |
|------|-----------|
| [`bin/blddash.rkl`](bin/blddash.rkl) | Пальмира |
| [`bin/blddash.rkr`](bin/blddash.rkr) | Радио-86РК 32 КБ |
| [`bin/blddash.rka`](bin/blddash.rka) | Апогей БК-01 |

## Три таргета (исходники)

| Каталог | Машина | Сборка пишет в |
|---------|--------|----------------|
| корень репо | **Пальмира** (расширенный РК) | `bin/blddash.rkl` |
| [`RK86/`](RK86/) | штатный **Радио-86РК 32 КБ** | `bin/blddash.rkr` — см. [`docs/RK32.md`](docs/RK32.md) |
| [`Apogee/`](Apogee/) | **Апогей БК-01** | `bin/blddash.rka` |

Физика и пещеры общие по смыслу; железо (экран, звук, лимиты ОЗУ) у каждого своё.
Сборка каждого таргета — из его каталога своим `compile.bat`.

## Сборка (Пальмира)

Нужен [z88dk](https://github.com/z88dk/z88dk) в PATH и Python 3.

```
compile.bat
```

или вручную:

```
zcc +radio86 main.c bd_levels.c caves_zx.c game_logic.c rockford.c text_util.c sprite_routines.c tiles.c labirint.c title.c -create-app
python make_rkl.py
```

Результат: `bin/blddash.rkl` — загрузить в Emu80 (платформа Радио-86РК / Пальмира).

**Лимит:** `a.bin` не должен превышать **42300 байт**. Код растёт от `0x0000`;
за `0xA5FF` начинается видеопамять. После любой добавки: `wc -c a.bin`.

## Карта памяти

```
0x0000 – 0xA5FF   бинарник игры
0xA600 – 0xB5FF   видеопамять ВГ75 (78 байт/строка, поле с 0xA69C)
0xB600+           стек
0xC000 – 0xC001   кадровый импульс ВГ75 (vsync, бит 0x20)
0xC200            клавиатура
0xCC00            PIT8253 (звук)
0xD000            таблица смещений строк
0xD800 – 0xDFFF   знакогенератор (псевдографика 2x3)
```

## Исходники

| Файл | Что внутри |
|------|------------|
| `main.c` / `main.h` | вход, тик, HUD, PRNG, клавиатура, карта памяти |
| `objects.h` | коды клеток work_cave (пусто, валун, scanned, взрыв…) |
| `sprites.h` | extern всех спрайтов и таблиц анимации |
| `game_logic.c` | физика C64: скан 800 клеток, падение, амёба, критеры |
| `labirint.c` | рендер: MapObj[], dirty-cell show_window, sprites_anim |
| `tiles.c` | все игровые тайлы 12×12 |
| `rockford.c` | спрайты и idle Rockford |
| `bd_levels.c` | nibble+RLE распаковка, камера, въездной скролл |
| `caves_zx.c` | 20 сжатых пещер A–T |
| `title.c` | заставки, музыка, SFX, защита бренда PALMIRA |
| `sprite_routines.c` | блитер спрайтов с заголовком (буквы, цифры) |
| `text_util.c` | шрифт, clrscr, таблица строк |

Исходные PNG кадров (амёба, idle, муар extra-life) лежат в `sprites/` —
в бинарник они не входят, массивы уже в `tiles.c` / `rockford.c`.

Подробности: [docs/](docs/) (`CLAUDE.md`, журнал `STATUS.md`, отладка Emu80).

## Управление

Стрелки — ходить, Пробел/Ввод — fire (толкать валун, копать на месте,
рестарт после смерти). **P** — пауза (ещё раз P — продолжить).
**AP2** — суицид (взорвать Rockford на месте). На титульнике — выбор пещеры.

## Замечание по z88dk

Внутри `#asm … #endasm` **нельзя** ставить апостроф или кавычку даже
в комментарии `;` — препроцессор считает `'` началом символьной константы
и глотает всё до следующего апострофа вместе с `#endif`.
Писать `couldnt`, не `couldn't`.
