## 6. Видеоподсистема и работа с экраном

### 6.1. Базовые возможности

Экран в РК86 текстовый, за формирование изображения отвечает связка ВГ75 + ВТ57: контроллер ПДП по запросу ВГ75 пересылает байты из экранной области ОЗУ во внутренний буфер ВГ75, который выводит их через ПЗУ знакогенератора на телевизор. Попутно с выборкой информации из экранной области происходит регенерация динамического ОЗУ.

Стандартная рабочая область экрана, с которой работают процедуры Монитора для вывода на экран, имеет размер 64×25 символов. Данная область может быть расширена путем прямого программирования контроллеров и прямой записи в видео-ОЗУ (см. ниже).

Знакогенератор содержит 128 символов, формат знакоместа символа — 6×8 пикселей. Кодировка символов в основном соответствует кодировке КОИ-7 Н2 (латинские буквы 40H–5FH, русские — те же позиции +20H), в области 00h–1Fh содержатся некоторые служебные символы, а также символы псевдографики. Служебные символы включают символы стрелок, человечка, яблока и т.п. и часто используются в играх. Псевдографика включает 16 символов с разбиением знакоместа 2×2, что даёт в стандартном режиме 64×25 разрешение 128×50. Назначение битов символов псевдографики:

| Бит | Назначение |
| - | - |
| 6 | 0 |
| 5 | 0 |
| 4 | правый нижний |
| 3 | левый нижний |
| 2 | 0 |
| 1 | правый верхний |
| 0 | левый верхний |

Базовая работа с экраном возможна с помощью системных вызовов F809h, F818h и F821h, которые функционируют в пределах рабочей области 64×25 знакомест. При этом можно использовать следующие управляющие символы:

| Код | Действие |
|---|---|
| 07h | звуковой сигнал |
| 08h / 18h / 19h / 1Ah | курсор влево / вправо / вверх / вниз |
| 0Ah | перевод строки (в нижней строке — скроллинг экрана вверх) |
| 0Ch | курсор в начало экрана |
| 0Dh | возврат каретки (курсор в начало строки) |
| 1Fh | очистка экрана |
| 1Bh, 59h («Y»), Y+20h, X+20h | последовательность АР2: установка курсора в координаты (X: 0–63, Y: 0–24 от левого верхнего угла) |

С помощью вызовов Монитора невозможно вывести один из символов псевдографики с кодом 07h, так как этот код зарезервирован для вывода звукового сигнала.

## 8. Клавиатура

Для работы с клавиатурой можно использовать:
- Процедуры Монитора F803h/F812h для ожидания нажатия клавиши и определения факта нажатия. В этом случае генерируется звуковой сигнал при нажатии, работает автоповтор и реализуется устранение дребезга контактов. Применяются для ввода текста.
- Процедуру Монитора F82Bh. Не ожидает нажатия клавиши, отрабатывает быстро, обычно применяется в играх.
- Непосредственный опрос матрицы клавиатуры.

Основная матрица клавиатуры имеет размерность 8×8, отдельно выделены клавиши СС, УС и РУС/ЛАТ. Для программного сканирования в порт A (8000h) выводится бегущий ноль по столбцам, из порта B (8001h) читаются строки.

### 10.1. Схемы цветности

Для РК-86 было предложено несколько схем цветности, которые задействовали атрибуты GPA0, GPA1 и HGLT контроллера ВГ75. Схемы давали возможность использовать 8 цветов в качестве цвета переднего плана, хотя различались деталями реализации. Также все схемы цветности задействовли сигнал RVV ВГ75, что позволяло использовать атрибут инверсного изображения, а также курсор в виде инверсного блока.

Для включения цвета необходимо записывать в экранную область байты атриботов следующего формата:

| Бит | Назначение |
|---|---|
| 7 | 1 |
| 6 | 0 |
| 5 | Underline (подчеркивание) |
| 4 | RVV (инверсия) |
| 3 | GPA1 |
| 2 | GPA0 |
| 1 | Blink (мерцание) |
| 0 | HGLT |

ВГ75 при этом необходимо либо запрограммировать в режим непрозрачных атрибутов для отображения атрибутов как пробелов, либо особым образом распределить экранную область для использования прозрачных атрибутов. Детали см. в документации на i8275.

Из-за особенностей схем цветности действие атрибутов цвета и инверсии смещено на одно знакоместо влево, это необходимо учитывать при программировании.

Кроме схем цветности часто встречались доработки, позволявшие без использования цвета использовать в РК-86 атрибут инверсии, а также менявшие прерывистое подчеркивание оригинального РК-86 на спллошное.

#### 10.1.1. Схема Толкалина

Данная схема была описана в журнале «Радиолюбитель» № 4 за 1992 год. Назначение атрибутов в данной схеме:

- HGLT — красный (red)
- GPA0 — зеленый (green)
- GPA1 — синий (blue)

В случае использования нулевых атрибутов (значения по умолчанию) все 3 цветовых составляющих будут равны 0. Для для запуска черно-белых программ в таком случае в оригинальной доработке предусмотрен переключатель в черно-белый режим. Однако существовали дополнительные модификации, где данный случай выделялся особо и давал белый или серый цвет, так же оно обычно реализовано и в эмуляторах.

#### 10.1.2. Схема Акименко

Эта схема под названием «Самоцвет-М» была описана в журнале «Радиолюбитель» № 10 за 1992 год как альтернатива схеме Толкалина. В схеме используются инвертированные биты атрибутов, что дает по умолчанию белый цвет и избавляет от необходимости особым образом учитывать не рассчитанные на цвет старые программы. Назначение атрибутов:

- ~HGLT — синий (blue)
- ~GPA0 — красный (red)
- ~GPA1 — зеленый (green)
